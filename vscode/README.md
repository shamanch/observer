# Witness для VS Code

Тонкая обёртка над CLI: расширение не проверяет код само, а вызывает `witness`.
Так логика живёт в одном месте, а расширение можно менять без риска разойтись с CLI.

## Команды

| Команда | Что делает |
|---|---|
| `Witness: инициализировать проект` | `witness init` |
| `Witness: критерии приёмки задачи` | спрашивает задачу и открывает терминал с `witness claim "…"` — критерии утверждает человек |
| `Witness: проверить результат` | `witness run` в панели вывода `Witness` |
| `Witness: открыть отчёт` | `witness report` и открывает `.witness/report.html` |

`claim` намеренно запускается в терминале, а не в фоне: подтверждение критериев —
ключевая часть продукта, её нельзя проскочить.

## Настройка

По умолчанию расширение ищет команду `witness` в `PATH`. Если CLI не установлен глобально:

```json
{
  "witness.cliPath": "node C:/Users/admin/witness/bin/witness.js"
}
```

## Запуск при разработке

1. Откройте папку `vscode/` в VS Code.
2. `F5` → откроется окно Extension Development Host.
3. В нём откройте проект с `.witness/` и запускайте команды из палитры (`Ctrl+Shift+P`).

Сборка не нужна: расширение написано на CommonJS и запускается как есть.
Проверка синтаксиса: `node --check src/extension.cjs`.
